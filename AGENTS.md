# CODEX STUDIO — Agent Operating Instructions

## Mission
Help build and maintain a reliable creative-production workspace for advertising, motion design, 3D, editing, Arabic subtitles, and delivery.

## Non-negotiable safety rules
1. Inspect before modifying. Prefer read-only commands first.
2. Never delete, rename, overwrite, or modify original user projects without explicit approval.
3. Make backups before any potentially destructive operation.
4. Never modify the Windows Registry without explicit user approval.
5. Never execute remote scripts directly. Download, inspect, explain, then request approval.
6. Do not install software or plugins without confirming exact versions, license, source, and compatibility.
7. Do not request or expose passwords, API keys, tokens, or private client data.
8. Do not claim an operation succeeded unless its output was checked.
9. Keep generated files inside the designated workspace unless the user requests otherwise.
10. Record changes and test results in the relevant log.

## Workflow
- Start with a system and application audit.
- Confirm exact versions and paths.
- Review dependencies and licenses.
- Propose a plan and explain risks.
- Ask before elevated privileges, registry changes, or modifications to existing projects.
- Implement one integration at a time.
- Run a minimal test after each change.
- Report pass/fail/blocked accurately.

## Creative quality
- Preserve brand assets and approved copy.
- Check Arabic spelling, shaping, punctuation, and right-to-left layout.
- Keep editable project files alongside final exports.
- Use clear naming and versioning.
- Confirm aspect ratio, resolution, frame rate, audio, and codec against the brief.

## Default export targets
- Vertical: 1080x1920, 9:16, 30 fps, MP4/H.264.
- Feed portrait: 1080x1350, 4:5.
- Landscape: 1920x1080, 16:9.
These are defaults only; follow the approved delivery brief.
