# Test Plan

Run these tests on the target machine and record evidence:
1. Workspace setup script can be rerun without overwriting files.
2. Audit script completes and reports installed application versions accurately.
3. Blender opens a sample scene and renders a short frame sequence.
4. After Effects opens a sample composition and renders a short test.
5. Premiere imports media, plays a short timeline, and exports a valid MP4.
6. Arabic subtitle sample passes shaping, RTL, punctuation, timing, and final-render checks.
7. Final export is playable and matches the requested dimensions, frame rate, and codec.

This repository does not contain results from these tests. Add dated results only after execution.
