# Security Policy

## Reporting
Do not publish secrets, exploit details, or private client data in public issues. Report suspected vulnerabilities privately to the repository maintainer.

## Safe use
- Inspect third-party source before execution.
- Verify release provenance and checksums when available.
- Avoid unnecessary administrator privileges.
- Keep credentials in a local secret manager or environment variables; never commit them.
- Treat generated scripts and AI output as untrusted until reviewed.
