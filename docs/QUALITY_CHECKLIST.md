# Quality Control Checklist

## Brief and brand
- [ ] Correct client, offer, audience, and CTA
- [ ] Approved logo, colors, fonts, and brand assets
- [ ] No unsupported claims or unlicensed assets

## Visuals and motion
- [ ] Consistent composition and visual hierarchy
- [ ] No unwanted cropping or flicker
- [ ] Motion timing and transitions are intentional
- [ ] 3D renders have acceptable lighting, shadows, materials, and noise
- [ ] Text remains within platform-safe areas

## Arabic and subtitles
- [ ] Correct spelling and punctuation
- [ ] RTL direction is correct
- [ ] Arabic letters connect and shape correctly
- [ ] Font supports all glyphs and diacritics used
- [ ] Mixed Arabic/English/numerals display correctly
- [ ] Subtitle timing and line breaks are readable

## Audio
- [ ] Voice is intelligible
- [ ] No clipping, clicks, or unwanted silence
- [ ] Music/SFX are licensed for intended use
- [ ] Mix is balanced on headphones and phone speaker

## Export
- [ ] Correct aspect ratio and resolution
- [ ] Correct frame rate
- [ ] Correct codec/container
- [ ] Export plays from beginning to end
- [ ] Final file name and version are correct
- [ ] Final export archived and backed up
