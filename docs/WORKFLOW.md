# Production Workflow

## Creative brief
Capture: client, objective, audience, platform, offer, key message, CTA, brand rules, references, duration, aspect ratio, deadline, and required deliverables.

## Concept and script
Create a clear hook in the first seconds, one central message, a concise body, and a direct call to action. Keep claims factual and approved by the client.

## Storyboard
For each shot, record:
- Shot number and duration
- Visual description
- Camera angle/movement
- On-screen copy
- Voice-over/dialogue
- Transition
- Required assets
- Production application

## Production
Keep source assets, editable project files, renders, audio, and exports organized. Use non-destructive editing and versioned project files.

## Review
Review the actual exported file, not only the timeline preview. Check visual quality, Arabic text, audio peaks, clipping, color, aspect ratio, frame rate, codec, and file integrity.

## Delivery
Deliver the approved export plus editable project/source files when included in the scope. Archive the final version and note its settings.
