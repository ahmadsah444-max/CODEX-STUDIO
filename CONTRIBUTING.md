# Contributing

Thanks for helping improve CODEX STUDIO.

## Before contributing
- Explain the use case and expected benefit.
- Check the license of every dependency and asset.
- Do not commit client work, personal data, credentials, API keys, or licensed assets without redistribution rights.

## Code and automation
- Prefer PowerShell compatible with Windows 10/11.
- Make scripts safe to rerun.
- Default to read-only behavior.
- Clearly identify any operation requiring administrator privileges.
- Never silently modify the Registry or overwrite user files.
- Include a test procedure and expected output.

## Pull requests
Include a summary, affected files, compatibility notes, risks, and test results. Do not label work as tested unless the test was actually run.
